# company-cards

База «карточек компаний» — единый источник реквизитов (все коды + все банки) с
конструктором карточек. Статический сайт **без внешних зависимостей**: чистый
HTML/CSS/JS, данные в `data/companies.json`, сохранение — через GitHub API.

## Структура

```
company-cards/
├── index.html            # просмотр карточек (grid)
├── constructor.html      # форма ввода + живой предпросмотр, динамические банки
├── assets/
│   ├── styles.css        # оформление (системные шрифты, без CDN)
│   └── app.js            # загрузка JSON, рендер, форма, сохранение, экспорт
└── data/
    └── companies.json    # канон реквизитов (массив компаний)
```

## Модель карточки

```json
{
  "id": "axioma",
  "shortName": "ООО «Аксиома»",
  "fullName": "Общество с ограниченной ответственностью «Аксиома»",
  "legalAddress": "...", "actualAddress": "...", "director": "...",
  "codes": { "inn":"", "kpp":"", "ogrn":"", "okpo":"", "okato":"", "oktmo":"", "okogu":"", "okved":"" },
  "contacts": { "site":"", "email":"", "phone":"" },
  "banks": [ { "bankName":"", "rs":"", "bik":"", "ks":"" } ]
}
```

`banks` — массив: одна компания может иметь несколько банков.

## Использование

1. Открой `index.html` — все карточки из `data/companies.json`.
2. Открой `constructor.html` — выбери компанию или «+ Новая», заполни форму,
   смотри живой предпросмотр справа.
3. Вставь токен GitHub (scope `repo`) и нажми **Сохранить в репозиторий** —
   файл `data/companies.json` обновится через Contents API. Токен хранится
   только в текущей вкладке (`sessionStorage`), не коммитится.
4. **Экспорт JSON** — выгрузить актуальный `companies.json` локально.

## Публикация (GitHub Pages)

Включи Pages в настройках репозитория (Settings → Pages → branch `main`, `/`),
либо через API. Для приватного репозитория Pages требует тариф Pro/Team;
на бесплатном плане сделай репозиторий публичным.

## Локальный просмотр

GitHub API при сохранении требует сети и токен. Просмотр карточек работает
offline через `fetch('data/companies.json')` — достаточно открыть `index.html`
через локальный сервер (например, `python3 -m http.server`).
