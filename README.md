# company-cards

База «карточек компаний» — единый источник реквизитов (все коды + все банки + лицензии/аккредитации)
с конструктором карточек. Статический сайт **без внешних зависимостей**: чистый HTML/CSS/JS,
данные в `data/companies.json`. Никаких токенов, сохранения и регистраций — конструктор
только собирает карточку, данные правит человек (Sisyphus) вручную.

## Страницы

- **[Главная — карточки компаний](https://axiiom-ru.github.io/company-cards/)** — просмотр
  карточек с переключателем компании.
- **[Конструктор карточек](https://axiiom-ru.github.io/company-cards/constructor.html)** —
  выбор компании, банка и нужных полей, живой предпросмотр в A4-пропорциях, печать/PDF,
  копирование текста, выгрузка HTML.

## Структура

```
company-cards/
├── index.html            # просмотр карточек (переключатель компании)
├── constructor.html      # конструктор: сборка карточки под нужный банк и поля
├── assets/
│   ├── styles.css        # оформление (бумага, фирменный тёмно-синий, подложки)
│   ├── app.js            # загрузка JSON, рендер, конструктор, экспорт/копирование
│   ├── logo_axiom.svg     # фирменный логотип AXIIOM (SVG, Lora 500 — как у Атмосферы)
│   ├── backdrop_atmosfera.svg # подложка-иллюстрация (Атмосфера)
│   ├── backdrop_axioma.png # подложка: мраморный бюст (Аксиома)
│   └── favicon.svg
└── data/
    └── companies.json    # канон реквизитов (массив компаний)
```

## Модель карточки

```json
{
  "id": "axioma",
  "shortName": "ООО «Аксиома»",
  "fullName": "Общество с ограниченной ответственностью «Аксиома»",
  "legalAddress": "...", "actualAddress": "...", "director": "...",
  "registrationDate": "05.07.2024",
  "codes": {
    "inn":"", "kpp":"", "ogrn":"", "okpo":"", "okato":"", "oktmo":"",
    "okogu":"", "okved":"",
    "okfs": {"code":"16", "name":"Частная собственность"},
    "okopf": {"code":"12300", "name":"Общества с ограниченной ответственностью"}
  },
  "contacts": { "site":"", "email":"", "phone":"" },
  "banks": [ { "bankName":"", "bankInn":"", "rs":"", "bik":"", "ks":"" } ],
  "licenses": [ { "number":"", "date":"", "type":"", "issuer":"" } ]
}
```

- `banks` — массив: одна компания может иметь несколько банков.
- `licenses` — лицензии и аккредитации (например, аккредитация ИТ-организации Минцифры).

## Использование

1. **Главная** — выбери компанию в переключателе, карточка отрисуется в фирменном стиле
   с подложкой-статуей/логотипом.
2. **Конструктор** — выбери компанию, банк (или «— все банки —») и отметь нужные поля
   галочками. Справа живой предпросмотр в A4-пропорциях.
   - **Печать / PDF** — сохранить в PDF (ровно одна страница A4).
   - **Копировать текст** — скопировать реквизиты в буфер.
   - **Выгрузить HTML** — скачать собранную карточку отдельным файлом.

## Данные

Данные в `data/companies.json` правит Sisyphus вручную по запросу. В репозитории
находятся две компании: **ООО «Аксиома»** (4 банка) и **ООО «Атмосфера»** (2 банка).
Новая компания добавляется через изменение JSON — в конструкторе заводятся только
свои поля, без ввода токенов и сохранения.

## Локальный просмотр

Открой через локальный сервер (например `python3 -m http.server`), потому что
`fetch('data/companies.json')` не работает при открытии файла напрямую (`file://`).
